« Mes box » — toujours visible

L'onglet 🍱 (renommé « Mes box ») doit rester accessible sans scroller la rangée de pills. 3 dispositifs.

A

Mes box en premier

Il devient la 1ʳᵉ pill, avant les jours. Ouverture du Menu = Mes box par défaut, les jours suivent. Simple, mais le dernier jour du cycle est alors lui-même hors écran.

B

Mes box épinglé à droite

La rangée se scinde : les jours scrollent à gauche, « 🍱 Mes box » reste épinglé à droite, séparé par un trait vertical. Les deux existent en permanence, aucun compromis.

Bolo Curry Pâtes
🍱 Mes box
C

Chip au-dessus de la progression

Les pills jours restent seules ; « 🍱 Mes box » devient une chip pleine largeur au-dessus de la barre « Dîners n/m · Boxes n/m ». Toujours visible, mais sort de la rangée — hiérarchie plus « à part ».
